# CodedPraveen - Personal Portfolio

A sleek, modern, and responsive portfolio website designed to showcase my identity, technical skills, and professional work as a **Web Developer**.

## 🚀 Overview
The [CodedPraveen](https://codedpraveen.com/) portfolio serves as a central hub for my digital presence. It is built with a focus on performance and clean UI, providing recruiters and collaborators with a direct look at my capabilities.

## 🛠️ Tech Stack
This project utilizes a modern full-stack developer kit:
* **Frontend:** [React](https://react.dev/) & [Next.js](https://nextjs.org/) for server-side rendering and optimized performance.
* **Styling:** Custom CSS/Tailwind for a dark-themed, professional aesthetic.
* **Deployment:** [Vercel](https://vercel.com/) for seamless hosting and CI/CD.

## ✨ Key Features
* **Dynamic Hero Section:** Features a typing animation and a custom character illustration to engage visitors immediately.
* **Skill Showcase:** Visual representation of core competencies including **HTML5**, **CSS3**, **JavaScript**, **React**, **Next.js**, and **MongoDB**.
* Visit my [GitHub profile](https://github.com/CodedPraveen).
* **Responsive Design:** Fully optimized for desktop, tablet, and mobile viewing.
* **Social Integration:** Links to professional networks like LinkedIn and X (Twitter) for easy networking.
