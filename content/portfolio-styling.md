# Portfolio Styling Guide

This guide captures the styling choices used in the CodedPraveen portfolio project.

## Theme

- Primary background: `#0b1220`
- Accent color family: indigo and blue
- Card surfaces: dark slate with soft borders

## Typography

- Bold headings for section hierarchy
- Comfortable body text spacing for readability
- Muted text color for long paragraphs

## Layout Tips

Use centered containers and balanced spacing:

```css
.wrapper {
  max-width: 700px;
  margin: 0 auto;
  padding: 2rem 1.25rem;
}
```

## Card Pattern

The project card style uses:

- rounded corners
- subtle border
- gentle hover transition

Readability always comes before visual complexity.
